# Linux & VMware Lab

Practical Linux administration and VMware lab.

## Objectives

- Practice Linux system administration
- Manage users, groups and permissions
- Troubleshoot services and system issues
- Monitor disk, memory and CPU usage
- Configure and troubleshoot SSH
- Practice networking troubleshooting
- Automate administrative tasks with Bash
- Practice VMware administration and troubleshooting
